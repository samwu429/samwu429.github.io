Project 01

Live + Open Source

001program - Mind Map Workspace

A browser-based canvas app for visual thinking. Users can create multiple boards, sketch idea nodes by drag-to-create, connect relationships, attach images, and keep work saved automatically in either local guest mode or cloud mode.

The project uses React + TypeScript + Vite, with Firebase authentication and cloud document storage. It includes undo/redo history, viewport pan/zoom controls, bilingual UI (English/Chinese), board import/export JSON, and a clean home/editor split for fast workflow switching.
